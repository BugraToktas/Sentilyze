# TriSential

Türkçe e-ticaret, mekan yorumları ve genel olarak her çeşit metin için geliştirilmekte olan duygu analizi (sentiment analysis) projesi.

## Teknolojiler

- **Backend:** FastAPI + HuggingFace Transformers
- **Frontend:** Expo (React Native)
- **Veritabanı:** Supabase
